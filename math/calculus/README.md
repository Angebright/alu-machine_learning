# Calculus

This project covers foundational calculus concepts used in machine
learning: summation/product notation, series, derivatives, the product
and chain rules, partial derivatives, and single/double integrals.

## Learning Objectives
- Summation and Product notation
- What is a series?
- Common series
- What is a derivative?
- What is the product rule?
- What is the chain rule?
- Common derivative rules
- What is a partial derivative?
- What is an indefinite integral?
- What is a definite integral?
- What is a double integral?
