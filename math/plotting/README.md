# Plotting

This project covers plotting data using matplotlib in Python.

## Learning Objectives
- What is a plot?
- What is a scatter plot, line graph, bar graph, and histogram?
- What is matplotlib?
- How to plot data with matplotlib
- How to label a plot
- How to scale an axis
- How to plot multiple sets of data at the same time

## Files
- 0-line.py - Plots a cubic function as a line graph
- 1-scatter.py - Plots height vs weight as a scatter plot
- 2-change_scale.py - Plots exponential decay with a log-scaled axis
- 3-two.py - Plots two decay curves on one graph with a legend
- 4-frequency.py - Plots a histogram of student grades
- 5-all_in_one.py - Combines all previous plots into one figure
- 6-bars.py - Plots a stacked bar graph of fruit quantities
