# Probability

This project implements probability distributions in Python 3 without importing any modules.

## Files
- `poisson.py`: Poisson distribution (init, PMF, CDF)
- `exponential.py`: Exponential distribution (init, PDF, CDF)
- `normal.py`: Normal distribution (init, z-score, x-value, PDF, CDF)
- `binomial.py`: Binomial distribution (init, PMF, CDF)
